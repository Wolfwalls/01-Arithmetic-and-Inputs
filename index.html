Javascript Arithmetic Operators

  • Operands: THe values or variables you're doing math with (eg. x+ 5), both are Operands
  • Operators: the symbols that tell the computer what math to do (+-, *, /, %, **) are all operators
  • The order of Operations is (PEMDAS)
    1. Parentheses
    2. Exponents
    3. Multiplication/Division
    4. Addition/Subtraction
